# Christoffel-s-App
The app has two screens, It can be used of a mobile device . The app lets a chef add menu items and view them in a live-updating list.
# Features of the App
The app has a Home screen with a flat list of all menu items and an empty list.
An Add Menu screen which shows the dish name, description, course (Picker) and price.
Validation with error message for required fields and invalid prices.
A success confirmation after saving a dish.
Lastly a list that updates automatically when a new item is added.

# More additional information about the app
The Christoffel's Menu App is a mobile application built for a restaurant owner and a chef who wants to move away from handwritten paper based menus. The app is designed for a non technical user, so every screen is kept simple, with large readable text, clearly labelled fields and obvious buttons.
